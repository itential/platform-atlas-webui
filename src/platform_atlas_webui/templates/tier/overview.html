{# Standard #}

Standard

application audit
{% if is_std %}Active{% else %}Available{% endif %}

Connects via Platform OAuth and an optional IAG4 API token. No server credentials required.

Recommended for ongoing monitoring and locked-down environments where SSH/database access isn't permitted.

  • ~54 rules across platform and gateway4 categories
  • No SSH, no MongoDB, no Redis
  • Works in strict or locked-down environments
  • Fastest — no infrastructure collectors to run
{% if not is_std %}
What changes if I switch to Standard?

Atlas will use only Platform OAuth (and an optional IAG4 token). MongoDB, Redis, SSH, and all infrastructure collectors go inactive; about 54 rules are evaluated instead of ~107.

What stays the same: existing captures and reports keep their original tier context. Extended-tier sessions become view-only until you switch back — no re-running capture, validate, or report on them.

Not sure which tier fits? Itential's Customer Success team can help — support@itential.com.

Extended

infrastructure audit
{% if not is_std %}Active{% else %}Available{% endif %}

Full infrastructure access — SSH into servers, query MongoDB and Redis directly, and inspect gateway configs.

Recommended for quarterly reviews and deep health audits where infrastructure-level visibility matters.

  • ~107 rules — all Standard rules plus infrastructure checks
  • SSH, MongoDB, Redis, IAG, system, filesystem, and Kubernetes collectors
  • Requires SSH keys and database credentials to be configured

What happens when I switch to Extended?

Extended enables full infrastructure collectors — SSH, MongoDB, Redis, IAG, system, filesystem, and Kubernetes. All ~107 rules are evaluated.

Next you'll add the credentials Extended needs: SSH host(s) & key path, MongoDB URI, Redis URI, and an IAG4 API token if applicable. With Vault, add the keys there and use Re-check; with the OS keyring or encrypted file, you'll enter them on the setup screen and Atlas verifies on the spot.

Need a hand getting set up? Itential's Customer Success team can help — support@itential.com.
